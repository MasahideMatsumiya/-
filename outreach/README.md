# Buddy-Buddy ドライフード 取扱い案内 — 下書き生成ツール

ペット施設リスト（公開連絡先）向けに、**施設名を差し込んだ案内メールの下書きを生成**するツールです。
**送信は行いません。** 中身を目視確認してから、配信サービス取込み or 手動送信に使います。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `source_list.csv` | 元リスト（189件） |
| `clean_list.py` | リスト整形。送信可能な行だけ抽出 |
| `clean_list.csv` | 整形後の送信用リスト（**43件**） |
| `needs_review.csv` | メール無し/要確認（146件・フォーム連絡のみ等） |
| `template.txt` | 差し込みテンプレ（件名+本文+署名+配信停止文） |
| `config.json` | 差出人・署名情報（**送信前に必ず記入**） |
| `generate_drafts.py` | 下書き生成 |
| `drafts/` | 1件ずつの下書き |
| `drafts_preview.md` | 全件まとめプレビュー |

## 使い方

```bash
# 1. リストを整形
python3 outreach/clean_list.py

# 2. config.json の (　) を実際の差出人情報に書き換える

# 3. template.txt の商品特長を埋める

# 4. 下書きを生成して目視チェック
python3 outreach/generate_drafts.py
#    → outreach/drafts_preview.md を開いて全43件を確認
```

リストや文面を直したら 1→4 を繰り返す（＝テストを重ねる）。

## ⚠️ 送信に関する重要な注意

このツールは下書き作成まで。実際の送信は次を守ってください。

1. **Gmailでの機械的な一斉/連続送信はしない**
   未同意宛先への営業送信はGmail規約違反でアカウント凍結リスク。
   1件ずつ小分けにしても回避にはならない。
2. **送るなら配信サービス経由**（Brevo / Mailchimp / Benchmark 等）
   到達率管理・配信停止が標準。`clean_list.csv` をそのまま取り込める。
3. **法令順守**（特定電子メール法・特商法）
   - 送信先は「事業者が公式サイト等で公表したアドレス」に限る
   - 相手が「広告お断り」を表示している場合は送らない
   - 本文に**差出人情報・連絡先・配信停止の方法**を明記（テンプレに反映済み）
4. **個人ドメイン宛(flag列)は1件ずつ要判断**。
